Why direct transfer is appropriate
- 639 relevant native ELF files were checked with readelf. Maximum required GLIBC
  version is 2.34; the locally compiled mmdet3d operators require 2.32. Ubuntu 20.04
  cannot run these operators unchanged. Ubuntu 24.04 matches the source host ABI.
- No external or broken prefix symlink was found. The prefix is independently complete.
- The mmdet3d editable link points to /mnt/d/CoopTrack_Audit/code/mmdetection3d;
  bind the audit workspace to that identical absolute path.
- Existing official torch/cu111, mmcv-full1.4.0, mmdet2.14.0, mmseg0.14.1 and
  mmdet3d0.17.1 remain intact. This avoids another torch download or operator build.
- Do not set LD_LIBRARY_PATH to prefix/lib: that could change torch's CUDA runtime
  selection. Docker's NVIDIA runtime supplies the driver libraries and device access.

    python /mnt/d/CoopTrack_Audit/docker/container_gate.py

Equivalent wrapper:
  bash /mnt/d/CoopTrack_Audit/docker/run.sh

run.sh defaults to container_gate.py. If the named container exists, it verifies its
image ID matches the selected tag, starts it only if stopped, then uses docker exec.
If absent, it creates a transient container with --gpus all, 2 GB shared memory and
both required binds. A name belonging to another image is preserved and rejected.
With explicit command arguments it runs that command:
  bash /mnt/d/CoopTrack_Audit/docker/run.sh python /mnt/d/CoopTrack_Audit/scripts/main_eval.py --help
